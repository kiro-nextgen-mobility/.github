# KIRO 차세대모빌리티연구팀

한국로봇융합연구원 · 차세대플랫폼연구단

로봇이 센서로 주변 공간을 이해하고 자연어 지시를 이동과 조작으로 이어갈 수 있도록, 피지컬 AI 기반 로봇 지능을 연구합니다.

## 연구 분야

| 분야 | 연구 내용 |
| --- | --- |
| 시각·언어·행동 | VLM·LLM으로 장면과 지시를 해석하고, VLA로 이를 로봇 동작에 연결하는 방법을 연구합니다. |
| 공간 메모리·자율 이동 | 관측한 물체와 위치를 공간 메모리에 기록해 목표를 찾고, 주변 상황을 반영해 이동 경로를 계획합니다. |
| 전신 제어·물체 조작 | 이동 베이스·몸통·팔을 함께 제어해 물체에 접근하고, 집고, 옮겨 놓는 동작을 연구합니다. |
